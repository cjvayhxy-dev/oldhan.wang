# Prompt Engineering 学习笔记

## 什么是 Prompt Engineering？

简单来说，就是学会如何跟 AI 说话，让它给出你想要的结果。

听起来简单，但实际上里面有很多讲究。

## 核心原则

### 1. 清晰具体

不要说"帮我写个文案"，而是说：

```
你是一个小红书运营专家。请为一款 AI 记账 App 写一条小红书笔记，
目标用户是 25-35 岁的上班族，风格活泼有趣，包含 3 个 emoji，
字数控制在 200 字以内。
```

### 2. 给出示例

Few-shot 是最有效的技巧之一。给 AI 看几个例子，它就能理解你要什么。

### 3. 分步引导

复杂任务拆成小步骤，让 AI 一步步来，质量会好很多。

## 实战心得

在做小红苕 App 的过程中，我大量使用了 Prompt Engineering：

- **需求分析**：让 AI 帮我梳理功能优先级
- **代码生成**：用详细的 prompt 生成高质量代码
- **文案创作**：批量生成小红书运营内容
